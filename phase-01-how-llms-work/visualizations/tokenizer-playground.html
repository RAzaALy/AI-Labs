Tokenizer playground

LLMs read tokens, not characters. This page trains a real byte-pair encoding (BPE) tokenizer on the corpus you type, then shows how new text gets split. Drag the merges slider: every merge glues the most frequent adjacent pair into a new vocabulary entry. (Real tokenizers start from UTF-8 bytes and do ~100k–200k merges. Here we start from characters so you can read the pieces.)

4 · Why non-English text costs more: UTF-8 bytes

Byte-level tokenizers start from bytes. ASCII letters are 1 byte, Arabic-script letters 2, CJK 3, emoji 4. If the training data had little of a script, few merges exist for it, so it stays split into many byte-sized tokens.
