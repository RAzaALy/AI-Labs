Inference: sequential, weights frozen 🔒

Generation must go one token at a time, because each new token depends on the previous one. No loss, no gradients, no weight changes. Your users' chats do not teach the model anything.

Web analogy: training is the CI build that produces an immutable artifact (the weights). Inference is running that binary in prod. Fine-tuning is a patch build. A prompt is per-request config.
