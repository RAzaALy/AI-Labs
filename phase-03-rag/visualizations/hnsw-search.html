HNSW: how an ANN index finds neighbours without checking everything

Each dot is a vector (2D here so you can see it; real ones have 384 to 3,072 dimensions). HNSW links every point to a few nearby points on several layers. A search starts on the sparse top layer, hops greedily toward the query, drops a layer, and repeats. On the bottom layer it keeps the ef_search best candidates while exploring. Click anywhere to search from there. (Simplified construction, same idea as pgvector's index.)
