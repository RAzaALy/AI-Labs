Streaming tokens over Server-Sent Events

A simulated stream, using the timing measured live in Lab 02 (Gemini free tier: TTFT ≈ 1 s, then ≈ 200 tokens/s). Watch the raw bytes arrive in network packets, the parser buffer half-lines (yellow), and the UI render deltas. Then break it: abort, buffer at a proxy, or fail mid-stream.

Controls

The decode speed is slowed down by default so you can watch it. Real APIs reach ~200 tok/s.
