Structured output: prompt-only JSON vs constrained decoding

The same model extracts a ticket from "I was charged twice for ORD-48213, refund NOW!". With prompt-only JSON it samples freely and drifts: a chatty preamble, a label that isn't in your enum, a code fence. With constrained decoding the sampler masks every token that would break the schema, renormalises, then picks. That's Phase 1's sampling with a grammar filter applied first. (Token candidates and probabilities are illustrative.)
