# Lab 06: Images and PDFs as input (≈45 min)

**Concept:** [theory/06-multimodal.md](../../theory/06-multimodal.md) · **Key:** optional

The fixtures in `fixtures/` are generated by [`fixtures/generate.ts`](fixtures/generate.ts) with no dependencies: a PNG bar chart with **no text** (so the model has to look) and a one-page invoice PDF.

## Task
In `starter/index.ts`:
1. `readChart`: send the PNG as a `file` part and get a typed `ChartReading` back.
2. `extractInvoice`: send the PDF and get typed `InvoiceFields` back.
3. `measureAttachmentTokens`: the same prompt with and without the image. What did the image cost?

## Run
```bash
npx tsx phase-02-llm-apis/labs/06-multimodal/check.ts starter
```

## What to notice (live run)
- Text-only prompt: **7** input tokens. Same prompt + a 400×240 PNG: **1,082**. **One small image ≈ 1,075 tokens.** Ten screenshots per request means ~10k tokens before you've said anything.
- PDFs are read natively (text **and** layout) by Gemini and Claude. A scanned PDF is just images, so it costs image tokens per page.
- Multimodal extraction pairs naturally with structured output: the image goes in, typed data comes out, and your code validates it.
- AI SDK 7: use `{ type: 'file', mediaType: 'image/png', data }`. The older `{ type: 'image' }` part is deprecated.
